# 🌶️ 重慶 7 天 6 夜智慧旅遊行程規劃中心 ‧ Travel Planner

Notion 風格的智慧旅遊行程規劃中心，具備 Firebase Firestore 雲端跨裝置即時雙向同步功能，並提供專屬獨立的**「極簡旅遊支出計算中心」**。

---

## 💰 專屬獨立頁面：極簡旅遊支出計算中心 (Travel Expense Calculator)

專為旅遊預算試算與即時記帳打造的極簡響應式計算中心：**[expenses.html](expenses.html)**。

### ✨ 核心特色
1. **預算與實際支出對比 (Budget vs Actual)**：
   - 預估總預算與實付總支出雙欄看板，即時計算收支差額與「結餘/超支」警示指標。
   - 每筆項目獨立登記預算、實付與支付狀態，清楚呈現單項差額。
2. **交通項目全方位可編輯**：
   - 大項交通（機票、高鐵、包車、保險等）清單每項皆可編輯模式、起訖路線/班次代碼與預算實付。
   - 每日市區交通（地鐵捷運、滴滴叫車、公車等）亦支援隨時編輯與路線自訂。
3. **每日分類細緻精算**：
   - **🍜 每日餐食**：早餐、午餐、晚餐、下午茶小吃依日獨立小計。
   - **🎫 每日景點**：門票、體驗活動、導覽等依日獨立小計。
   - **🚇 每日交通**：地鐵捷運、計程車叫車（滴滴）、公車等日常移動依日小計。
4. **交通大項與日常明確劃分**：
   - **✈️ 大項交通支出**：國際機票、跨省跨城高鐵、長途包車、保險、簽證等整趟固定大項。
   - **🚇 每日交通**：依日期獨立歸屬，清楚掌握每日市區交通成本。
5. **彈性住宿計算中心**：
   - **單日獨立計費**：依特定天數記錄不同飯店或浮動房價。
   - **連續多日區間**：支援輸入「每晚單價（自動乘晚數）」或「區間總額（自動每日均攤）」。
   - **整趟旅程包棟**：整筆費用自動均攤至全行程每一天。
   - 每日視圖自動標註入住飯店名稱與當日住宿攤提金額。
6. **多工作表 Excel (.xlsx) 試算表匯出**：
   - 整合 SheetJS 支援匯出含【支出總覽對比】、【每日支出明細】與【大項交通與住宿】三大工作表的完整 Excel 試算表。
7. **☁️ 雲端跨裝置即時同步與主行程一鍵連動**：
   - 串接 Google Firebase Firestore，手機與電腦雙向即時連動記帳。
   - 支援與主規劃手帳（`index.html`）一鍵同步活動、機票與飯店資料。
8. **極簡版面與視覺美學 (Clean & Minimalist)**：
   - 採用 `Plus Jakarta Sans` 現代字體與暖沙金膠囊標籤，主內容加寬滿版排版，大幅降低視覺干擾。
5. **全視窗自適應與手機深度適配**：
   - **電腦端 (100vh Full Window)**：左右雙欄自適應視窗，左欄為即時統計看板與趨勢圖，右欄為日期切換與明細卡片，無外層多餘捲軸。
   - **手機端 (Mobile First)**：水平滾動天數導覽列、底部固定即時金額預覽與浮動「+ 記一筆」大按鈕，單手點擊喚出滑入式 Bottom Sheet，編輯直覺順暢。
6. **多幣別與均攤試算**：
   - 支援基準幣別（如台幣 TWD）與當地外幣（如人民幣 CNY）雙向一鍵即時切換。
   - 支援「全團總額」與「每人平均」自訂分攤。
   - 支援離線 LocalStorage 自動儲存、匯出/匯入 JSON 備份檔、一鍵複製文字結算表、列印專用報表。

## 🌟 主行程規劃亮點
- **Notion 雙欄美學佈局**：快速導覽、雙住宿切換、交通航班資訊、即時匯率概算。
- **7 天魔幻山城時間軸**：精準收錄武隆天生三橋、長江索道、下浩里、三峽博物館、來福士烤匠、無人機表演、磁器口等深度行程。
- **☁️ 雲端跨裝置即時同步**：串接 Google Firebase Firestore，手機與電腦雙向即時連動，多人共同編輯免重新整理。
- **📖 隨身旅遊小手冊**：一鍵預覽並列印 A4 PDF 專屬旅遊隨身手冊。
- **🖼️ Notion 封面選擇器**：支援精選旅遊主題圖庫、本地電腦圖片上傳與網址連結。
